# Examples

Every script is self-contained: `python examples/<name>.py` opens a browser tab on the canvas it builds. Summaries are each script's docstring; this file is generated by `scripts/gen_examples_index.py`.

## Start here

- [`hello_world.py`](hello_world.py) — Minimal danvas demo: a slider and a label that mirrors it
- [`readme_tour.py`](readme_tour.py) — readme_tour.py — An interactive canvas that walks through the README in order
- [`frontend_backend_tour.py`](frontend_backend_tour.py) — An interactive tour of how the danvas frontend talks to the backend
- [`architecture.py`](architecture.py) — danvas, explained by danvas
- [`catalogue.py`](catalogue.py) — Catalogue: one column showcasing every native danvas component
- [`show_anything.py`](show_anything.py) — canvas.show(value) — auto-panel for every major Python data type

## Input, output and handlers

- [`action_routing.py`](action_routing.py) — Action routing with field validation (@panel.on(action, fields=...))
- [`readback_and_save.py`](readback_and_save.py) — Read-back + saving: watch the backend receive UI edits, then save the canvas
- [`dispatch_trace_demo.py`](dispatch_trace_demo.py) — Live demo of canvas.on_dispatch + trace_calls — watch handlers AND the calls
- [`download_button.py`](download_button.py) — Download files (or freshly-generated data) from the server to the viewer
- [`upload_button.py`](upload_button.py) — Receive a file from a viewer's browser into Python
- [`file_endpoints.py`](file_endpoints.py) — Build a file download + upload panel from scratch — no Download/Upload panel
- [`file_browser.py`](file_browser.py) — Browse a folder, pick a file, run a pipeline on it, see the result on canvas
- [`file_tree.py`](file_tree.py) — A file-tree browser as a React panel: Python walks the disk, JSX renders it

## Custom and React panels

- [`custom_html.py`](custom_html.py) — Custom HTML panel: hand-written markup that talks back to Python
- [`custom_component.py`](custom_component.py) — Build your own component from HTML — no source edits, no frontend rebuild
- [`custom_binary_stream.py`](custom_binary_stream.py) — High-telemetry binary streaming into a Custom panel (`push_binary`)
- [`custom_styled_component.py`](custom_styled_component.py) — Drop a uiverse.io CSS snippet into a Custom panel, unchanged
- [`react_component.py`](react_component.py) — Build a native canvas panel from your own React component — no npm, no rebuild
- [`react_request.py`](react_request.py) — React panel request/response: await an answer from Python
- [`react_canvas_api.py`](react_canvas_api.py) — React panel canvas API: viewport / setView / chat from user JSX
- [`react_styled_component.py`](react_styled_component.py) — A styled-components React widget as a native panel, no npm
- [`shared_components.py`](shared_components.py) — Shared React components + global CSS (canvas.define / canvas.style)
- [`analog_clock.py`](analog_clock.py) — Example: A custom analog clock component
- [`matplotlib_panel.py`](matplotlib_panel.py) — Matplotlib panel: render a figure to a PNG and show it in a Custom panel
- [`plotly_panel.py`](plotly_panel.py) — Interactive Plotly panel: a fully interactive chart inside a Custom panel
